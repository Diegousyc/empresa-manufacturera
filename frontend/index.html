Análisis de datos
ETL
Preparación de datos. Limpia y organiza la información para análisis.
¿Por qué?: Garantizar calidad y consistencia en los datos antes del análisis. ¿Qué identificamos?: Valores faltantes, duplicados, outliers y estructura de las tablas.
Regresión
Predicción de variables como eficiencia, calidad y comportamiento de máquinas.
¿Por qué?: Predecir métricas clave para anticipar problemas y planificar capacidad. ¿Qué identificamos?: Relación entre variables y factores que afectan rendimiento.
Clasificación
Clasifica productos (defectuoso/correcto) y comportamientos de máquinas.
¿Por qué?: Automatizar detección de defectos y categorizar casos para acción. ¿Qué identificamos?: Patrones que distinguen productos defectuosos de correctos.
Clustering
Agrupa máquinas con comportamientos similares para identificar patrones.
¿Por qué?: Encontrar segmentos y anomalías operativas sin etiquetas previas. ¿Qué identificamos?: Grupos de máquinas con performance parecido y posibles causas comunes.
